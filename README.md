# PPTX Chart Editor Lite

גרסה רזה של עורך הגרפים למצגות. זרימת עבודה אחת בלבד: עריכת כל הגרפים דרך אקסל.

## זרימת עבודה
1. העלאת קובץ `.pptx`
2. הורדת קובץ אקסל המכיל את נתוני כל הגרפים (גיליון לכל גרף)
3. עריכת הקובץ באקסל ושמירתו
4. העלאת האקסל המתוקן והורדת המצגת המעודכנת

## הפעלה
```bash
pip install -r requirements.txt
streamlit run app.py
```
