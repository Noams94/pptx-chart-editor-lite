# PPTX Chart Editor Lite

עורך גרפים רזה למצגות PowerPoint. עריכת כל הגרפים במצגת דרך קובץ אקסל אחד — גיליון לכל גרף.

אפליקציית Streamlit ב-RTL מלא בעברית.

## זרימת עבודה

1. **העלאת מצגת** — קובץ `.pptx` (או שימוש במצגת לדוגמה המצורפת).
2. **הורדת אקסל** — נוצר קובץ `.xlsx` עם גיליון נפרד לכל גרף שזוהה במצגת.
3. **עריכה באקסל** — שינוי הערכים, שמות הסדרות וקטגוריות, ושמירה.
4. **העלאת האקסל המתוקן** — האפליקציה מתאימה גיליונות לגרפים ומציגה אזהרות לגיליונות לא תואמים.
5. **הורדת המצגת המעודכנת** — קובץ `.pptx` חדש עם הנתונים המעודכנים, תוך שמירה על העיצוב והפורמט המקוריים של הסדרות.

## תכונות

- זיהוי אוטומטי של כל הגרפים (כולל גרפי XY/פיזור).
- שמות גיליונות ייחודיים לפי מספר שקופית ושם הצורה.
- שמירת פורמט הסדרות (`series_formats`) בעת עדכון.
- ולידציה של מספר עמודות מצופה לכל גרף לפני העדכון.
- ממשק עברית מלא עם תמיכה ב-RTL.

## התקנה והרצה

```bash
pip install -r requirements.txt
streamlit run app.py
```

האפליקציה תיפתח בדפדפן בכתובת `http://localhost:8501`.

## דרישות

- Python 3.9+
- streamlit ≥ 1.30
- python-pptx ≥ 0.6.23
- pandas ≥ 2.0
- openpyxl ≥ 3.1
- lxml ≥ 4.9

## מבנה הפרויקט

```
pptx-chart-editor-lite/
├── app.py                    # ממשק Streamlit וזרימת העבודה
├── core/
│   ├── data_extractor.py     # חילוץ נתוני גרפים מ-PPTX
│   └── data_writer.py        # עדכון מרובה גרפים בקובץ PPTX
├── sample.pptx               # מצגת לדוגמה
└── requirements.txt
```

## הערות

- הקובץ אינו משנה את עיצוב המצגת — רק את נתוני הגרפים.
- גיליונות שלא תואמים לגרף קיים (לפי שם) ידולגו ויסומנו באזהרה.
- מספר העמודות בגיליון חייב להיות ≥ למספר העמודות בגרף המקורי.
